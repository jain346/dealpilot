# DealPilot

Set up the Google credentials used by the ADK agents:

```sh
gcloud auth application-default login
```

Run the authenticated API from this directory:

```sh
uvicorn run_agent:app --reload
```

Open `http://127.0.0.1:8000/` for the browser UI. It provides account
creation, login, session management, and a conversation view for the agent.

The auth endpoints are mounted under `/auth`:

1. `POST /auth/signup` with JSON `{"username", "password", "email"}`
2. `POST /auth/token` with form fields `username` and `password`
3. Send its `access_token` as `Authorization: Bearer <token>`.

Authenticated workflow endpoints:

* `POST /agent/sessions` creates a conversation session for the caller.
* `POST /agent/sessions/{session_id}/messages` accepts `{"message": "..."}`
  and runs the DealPilot director workflow in that caller's session.
* `GET /agent/sessions/{session_id}/messages` retrieves that caller's saved
  transcript.

Session identifiers are generated by the server and are scoped to the JWT
subject, so one authenticated user cannot run another user's conversation.
Users, conversation ownership, and messages are persisted in SQLite. By
default the database is `dealpilot.db`; set `DEALPILOT_DATABASE_PATH` to place
it elsewhere. For production, configure a unique `DEALPILOT_JWT_SECRET` and
use a managed database instead of the local SQLite file.

The original local CLI remains available with `python run_agent.py`.

PROJECT_ID=$(gcloud config get-value project)

gcloud run deploy dealpilot \
  --source . \
  --region us-central1 \
  --platform managed \
  --allow-unauthenticated \
  --memory 2Gi \
  --cpu 2 \
  --timeout 300 \
  --set-env-vars \
GOOGLE_GENAI_USE_ENTERPRISE="TRUE",\
GOOGLE_CLOUD_PROJECT="${PROJECT_ID}",\
GOOGLE_CLOUD_LOCATION="us",\
PARALLEL_API_KEY="",\
DEALPILOT_JWT_SECRET="$(openssl rand -hex 32)"
